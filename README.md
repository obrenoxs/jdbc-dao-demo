# JDBC DAO Project

Project developed during my Java studies to practice database access using JDBC and the DAO (Data Access Object) pattern.

## Technologies

* Java
* JDBC
* MySQL
* Eclipse IDE

## Features

* Database connection management
* Data insertion
* Data retrieval
* Data update
* Data deletion
* Transaction control
* Exception handling

## Concepts Practiced

* JDBC API
* PreparedStatement
* ResultSet
* Transactions (Commit and Rollback)
* DAO Pattern
* Factory Pattern
* Object Persistence
* SQL Queries
* Exception Handling
* Separation of Responsibilities

## Entities

* Seller
* Department

## Implemented Operations

### Seller

* Find by ID
* Find by Department
* Find All
* Insert
* Update
* Delete

### Department

* Find by ID
* Find All
* Insert
* Update
* Delete

## Learning Objectives

This project was developed to strengthen my understanding of relational databases, SQL operations, JDBC programming and software design patterns commonly used in backend development.
